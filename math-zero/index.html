一、认识数字0

0 有两个意思：①表示一个也没有；②表示起点。

🍎 意思一：表示一个也没有

篮子里有 3 个苹果，点击苹果把它们拿走，看看最后还剩几个？

🏁 意思二：表示起点

0 是最小的数，也是数数的起点。

二、规范书写0

0 要写得圆润饱满，线条连起来，不能有缺口。

下面的虚线 0 是参考字，请在画板上照着描一描：

0
书写小贴士：
  • 从上方中间偏左一点的位置开始，逆时针画一个椭圆。
  • 线条要连贯，最后与起笔处自然相接，不留缺口。
  • 0 的大小要比 1、2 略大，形状饱满圆润。

三、0的三条计算规律

规律①：相同两数相减，得 0

4 - 4 = 0

4 个苹果，吃掉 4 个，一个也没有了。

规律②：一个数加 0，还等于原来的数

3 + 0 = 3

原来有 3 块糖，又拿来 0 块，还是 3 块。

规律③：一个数减 0，还等于原来的数

5 - 0 = 5

原来有 5 支铅笔，拿走 0 支，还是 5 支。

💡 记忆口诀：加 0 不变，减 0 不变，同数相减得 0。
